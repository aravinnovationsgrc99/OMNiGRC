# Environment Variable Documentation

| Variable Name | Environment Scope | Purpose |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Frontend & Backend | Public Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Frontend | Supabase Anon publishable key |
| `NEXT_PUBLIC_API_URL` | Frontend | NestJS REST API Base Endpoint |
| `SUPABASE_URL` | Backend | Supabase backend URL |
| `SUPABASE_SECRET_KEY` | Backend | Supabase Service Role key |
| `GEMINI_API_KEY` | Backend | Tier 1 LLM Provider API Key |
| `ANTHROPIC_API_KEY` | Backend | Tier 2 LLM Provider API Key |
| `PORT` | Backend | NestJS listener port (Default: 3001) |
